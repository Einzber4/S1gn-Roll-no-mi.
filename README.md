# Einzbern Roulette

Decision engine — projetos primeiro, distrações depois.

## Estrutura

- `index.html` — interface
- `css/style.css` — estilos
- `js/app.js` — lógica da aplicação
- `assets/` — recursos visuais
- `manifest.json` — configuração inicial de PWA

## Execução local

Abra `index.html` em um navegador ou utilize o Live Server no VS Code.

## Categorias

- Problemas / Dúvidas
- Jogos
- Sugestões / Projetos
- Músicas
- Imagens

Os dados da V1 são persistidos localmente no navegador.
